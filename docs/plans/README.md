# Local implementation plans

Plans are working checklists for open features. They are **gitignored**
(`docs/plans/*.md` except this README).

- Write plans here as `YYYY-MM-DD-<topic>.md` while implementing.
- Do not `git add` plan files.
- After implementation, delete the local plan file (agents should recommend this).
- Roadmap lives in GitHub issues, not in this directory.
